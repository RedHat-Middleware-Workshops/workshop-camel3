+
_Matrix_ does not provide a field to flag bot-generated messages, so we need to develop a custom pattern-matching approach to distinguish user messages from bot messages.

--

* `username@system:`  message

+
** *{user-username}@matrix:* ping
** *{user-username}@rocketchat:* pong
+
{blank}

cat << \EOF > r2m.camel.yaml
- route:
    description: RocketChat to Matrix
    from:
      uri: kamelet:webhook-source
      description: RocketChat
      variableReceive: rocketchat
      steps:
        - convertVariableTo:
            description: stream to String
            name: rocketchat
            type: String
        - choice:
            when:
              - steps:
                  - stop: {}
                jq:
                  source: rocketchat
                  expression: .text | test("\\*.*@.*:\\*")
        - log:
            message: ${body}
EOF
